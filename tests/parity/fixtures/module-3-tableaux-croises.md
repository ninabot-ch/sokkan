# Module 3 — Les tableaux croisés dynamiques

Formation « Tableur au quotidien », niveau intermédiaire. Durée du module : 90 minutes.

## Objectifs

À la fin du module, la personne est capable de :

- créer un tableau croisé dynamique à partir d'une plage de données propre ;
- choisir les champs de lignes, de colonnes, de valeurs et de filtres ;
- changer la fonction de synthèse (somme, nombre, moyenne) ;
- actualiser le tableau après une modification des données source.

## 1. Préparer les données

Un tableau croisé dynamique part d'une plage **sans ligne vide ni colonne vide**, avec **un titre par colonne**
sur la première ligne. On conseille de transformer la plage en tableau (menu Insertion, puis Tableau) : le
tableau croisé suivra alors les nouvelles lignes automatiquement.

## 2. Créer le tableau croisé

Sélectionner une cellule de la plage, puis menu Insertion, puis « Tableau croisé dynamique ». Choisir
« Nouvelle feuille » comme emplacement. La liste des champs s'ouvre à droite de l'écran.

## 3. Les quatre zones

- **Lignes** : les catégories affichées verticalement (par exemple le nom du vendeur).
- **Colonnes** : les catégories affichées horizontalement (par exemple le trimestre).
- **Valeurs** : ce qui est calculé (par exemple le chiffre d'affaires).
- **Filtres** : ce qui limite tout le tableau (par exemple une seule région).

Par défaut, un champ numérique placé dans Valeurs est **additionné** ; un champ texte est **compté**.

## 4. Changer la synthèse

Clic droit sur une valeur, puis « Synthétiser les valeurs par », puis Moyenne, Nombre, Max ou Min.
Pour afficher des pourcentages : « Afficher les valeurs » puis « % du total général ».

## 5. Actualiser

Un tableau croisé **ne se met pas à jour tout seul** quand les données changent : clic droit, puis
« Actualiser » (ou Données, puis « Actualiser tout »). C'est l'erreur la plus fréquente des débutants.

## Exercice

Avec le fichier « ventes-2025 », afficher le chiffre d'affaires par vendeur (lignes) et par trimestre
(colonnes), filtré sur la région Ouest, puis afficher la part de chaque vendeur en % du total général.
